怎么用这三份 HTML

1. 在 AI Studio 上按顺序跑：--mode train → --mode inference → --mode custom → --mode eval → --mode ops → --mode report；
2. 把 outputs/reports/ 里的单个 html 文件下载到本机，双击即可打开 —— 图片已 base64 内嵌，不需要联网、不需要拷贝其他文件、不需要装任何 Python 库；
3. 想缩小文件体积（改走相对路径引用图片）就加 --no_embed，此时必须把整个 outputs/ 目录一起拷走；
4. 交作业建议提交：model_report.html + ops_report.md + curves.png。
